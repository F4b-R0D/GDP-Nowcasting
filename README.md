# Nowcasting Peruvian GDP with High-Frequency Indicators

**Applied macroeconomics · Time series · Economic monitoring · Python**

This project explores how high-frequency indicators can be used to estimate current economic activity before official GDP releases become available.

The application focuses on **Peru** and uses electricity consumption and other leading indicators as timely proxies for aggregate economic activity.

## Research Motivation

Official GDP statistics are published with a delay. For policy analysis, budgeting, and economic monitoring, it is often useful to obtain a more timely signal of current economic conditions.

The central question of this project is:

> **How much information about current GDP can be recovered from high-frequency indicators available before the official national accounts release?**

## Approach

The repository combines:

- high-frequency economic indicators;
- electricity consumption as a proxy for economic activity;
- automated data preparation and transformation;
- time-series forecasting;
- Box–Jenkins / SARIMA modelling;
- exploratory analysis and visualization.
